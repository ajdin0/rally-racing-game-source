

\# Rally Racing Game — Source Code



A 3D arcade racing game developed in Unity using C#. This repository contains the original gameplay and multiplayer scripts from the project.



\## Features



\- Arcade vehicle physics and drifting

\- Surface-dependent vehicle handling

\- Multiple vehicles with unique driving characteristics

\- Six racing routes with checkpoints and lap tracking

\- Online multiplayer using Unity Netcode and Relay

\- Multiplayer synchronization and race coordination

\- Ghost vehicles with disabled collisions

\- Race countdown and starting boost

\- Local leaderboards and race timing

\- Vehicle selection, camera controls, and visual effects



\## Technologies



\- Unity 6

\- C#

\- Netcode for GameObjects

\- Unity Relay

\- Universal Render Pipeline (URP)



\## Project Structure



The `Scripts` directory contains the gameplay logic, including:



\- Vehicle controllers and physics

\- Racing and checkpoint management

\- Multiplayer networking

\- UI and player interactions

\- Audio and visual effect controllers



\## Important Note



This is a source-code showcase, not a complete Unity project.



Third-party models, tracks, textures, audio, and other licensed assets have been excluded. The scripts depend on Unity components and scene configurations that are not included in this repository.



\## Project Status



Completed playable prototype developed as a personal game development project.
